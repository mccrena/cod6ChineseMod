本项目为**个人独立技术制作**，基于本地神经声学 AI（IndexTTS 2.5）管线完成全战役 19 关角色的音色克隆与时长校准。无论您是体验 **普通原版战役（常规显示器游玩）** 还是搭配 **Overlord VR Mod（虚拟现实头显沉浸游玩）**，均可彻底告别看字幕的疲惫，沉浸在宏大逼真的战术交火与剧情演出中！

## 🌟 核心特色与制作亮点

1. **全战役 19 关战术语音全覆盖（9157 条音频，无死角汉化）**：
   - 涵盖从序幕《训练营》、雪山《绝岭雄风》、高潮迭起的《别说俄语》与《大撤退》，到华盛顿保卫战《第二阳光》、《威士忌旅馆》，以及阿富汗最终决战《收尾工作》的**全战役 19 个关卡**。
   - 语音总数达 **9157 条**，包含核心剧情对白、战术交火无线电、队友警戒提示、敌军战术呼叫与环境叙事广播，全程无英文对白残留。

2. **17 部高清 CG 过场动画全中文重制（1080P/4K 高码率）**：
   - 全战役所有任务加载与剧情过场动画全部中文化。
   - 采用多声道分轨与背景无损保留技术，在精准替换中央中文语音的同时，原汁原味保留 Hans Zimmer 史诗交响配乐与战场武器环境音效。

3. **角色原声音色克隆与时长对齐**：
   - 基于动视官方原声母带切片作为音色参考，尽力还原**普莱斯上尉（Captain Price）**、**肥皂（Soap MacTavish）**、**谢菲尔德将军（General Shepherd）**、**弗利中士（Sgt. Foley）**、**邓恩下士（Cpl. Dunn）**、**马卡洛夫（Makarov）** 等经典角色的硬汉战术语气。
   - 对齐原版时长与停顿节奏，最大程度避免吞字抢话。

4. **100% 匹配 COD 引擎底层流式 FLAC 规范**：
   - 严格遵循底层解码规范：`1024` 固定分块、48000Hz 单声道、内嵌 `APPLICATION (fsiz)` 元数据块与精确寻道表（SEEKTABLE），杜绝断音或静音。

5. **双补丁机制与非侵入式绿色覆盖**：
   - 纯绿色补丁架构，**不改动任何官方原生 .pak 数据文件**。
   - 附带全新编写的一键安装、一键卸载与完整性校验批处理脚本，秒装秒卸。

6. **全环境通用兼顾**：
   - **普通原版 PC 游戏**：原生兼容，开箱即玩。
   - **Overlord VR Mod**：原生兼容，空间音频直达头显。

## 📥 下载与安装方法

### 📦 下载专区
请前往 GitHub Releases 页面获取最新安装包：  
👉 **[GitHub Releases 下载链接](https://github.com/mccrena/cod6ChineseMod/releases)**

### 推荐安装步骤
1. **安装核心语音包（必选）**：
   - 下载 `MW2CR_Chinese_Audio_Mod_v1.1.zip`（约 705MB）。
   - 解压至您的 **游戏根目录**（包含 `MW2CR.exe` 或 `overlord.exe` 的文件夹）。
   - 双击运行 **`一键安装.bat`** 即可完成全战役 19 关核心语音部署。
2. **安装 CG 视频增强包（可选）**：
   - **方式一（单文件一键版，推荐）**：下载 `MW2CR_Chinese_CG_Pack_v1.1.7z`，解压覆盖至游戏根目录。
   - **方式二（免安装工具分卷版）**：下载 `MW2CR_Chinese_CG_Pack_v1.1_Part1.zip` 与 `Part2.zip`，解压后覆盖至游戏根目录。
   - 运行游戏根目录下的 `一键安装.bat`（或 `一键部署CG.bat`）完成快速路径镜像。

### 恢复官方英文
随时双击游戏根目录下的 **`一键卸载.bat`**，即可一键干净移除所有补丁，秒回官方原版英文。
